## 在线修改参数

点击地图底部的“编辑参数”即可打开 JSON 编辑器。编辑颜色、投影、灯光、图层显隐、柱图和信息点等配置后，点击“应用到地图”，或按 `Ctrl/Command + Enter`，当前三维场景会使用最新配置重新加载。

应用前会先检查配置是否发生变化；有变化时保留陕西省 GeoJSON，并使用最新的完整配置重新创建地图，避免局部更新投影或缩放时残留旧材质状态。

为避免一次性在编辑器中载入大量坐标，陕西省的 `mapJson` 与 `mapStroke` 不进入可编辑 JSON，始终使用 `example/data` 中的本地数据。编辑器提供格式化、恢复默认与 JSON 错误提示。

## 最小数据

```js
const mapData = {
  mapJson,
  geoProjectionCenter: [108.887114, 35.263661],
  geoProjectionScale: 85,
}
```

只有 `mapJson` 是业务侧必须提供的字段。投影中心和缩放值需要根据 GeoJSON 覆盖范围调整，否则地图可能不在镜头中央或尺寸不合适。
